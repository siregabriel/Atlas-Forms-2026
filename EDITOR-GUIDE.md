# Forms Hub — How to manage files

You can add, update and remove files in the Forms Hub yourself. Nothing is installed and no code is involved. Changes show up for everyone right away.

## Open the admin page

Log in to the Atlas internal site (atlasseniorliving.net), then either:

- click **📁 Manage Forms Hub** in the black bar at the top of the page, or
- open the Forms Hub and click **⚙️ Manage files** in the top right corner.

If you don't see either one, your account doesn't have access yet. Ask Gabriel Rosales to give you access.

## Get the right link from OneDrive

This is the most important step. A wrong link opens for you but not for anyone else.

1. Open OneDrive or SharePoint and find the file.
2. Click **⋯** next to the file and choose **Share**.
3. Open the link settings and choose **People in Atlas Senior Living**. Do **not** choose "Specific people".
4. Click **Copy link**.

Don't copy the address from the top of your browser. If you paste one of those, the form shows a yellow warning.

## Add a file

1. Click **+ Add a file**.
2. Paste the link.
3. Type the name people will see (no need to add .pdf or .docx — the type is picked for you).
4. Optional: choose a **Category**, a **State** (only if the file is for one state), and a **NEW** badge.
5. Click **Add file**.

## Replace a file with a newer version

**Easiest way — same file name (nothing to change in the Forms Hub):**

1. In OneDrive, upload the new version to the **same folder** with **exactly the same file name**.
2. When OneDrive asks, choose **Replace**.
3. That's it: the link stays the same, so the Forms Hub opens the new version. The old one is kept in OneDrive under **⋯ → Version history**.
4. Optional: in the admin page click **Edit** on the file, choose the **UPDATED** badge and **Save changes** so people notice it.

**If the new version has a different file name:**

1. Upload it to OneDrive and copy its link (see "Get the right link" above).
2. In the admin page, click **Edit** on the old file and paste the new link.
3. Choose the **UPDATED** badge and click **Save changes**.

Don't add it as a new file — editing keeps it in people's favorites.

## Remove a file

Click **Delete** next to the file and confirm. The file in OneDrive is **not** deleted — it only disappears from the Forms Hub.

## Badges

**NEW** and **UPDATED** turn off by themselves after 30 days.

## Categories and states

Go to **Categories & States** to add, rename or remove them. Renaming updates every file that uses it.

## Made a mistake?

Go to **Undo changes**, find the change, and click **Restore version before this**. The last 15 changes are kept.

## Links to check

In the category filter, choose **⚠ Links to check** to see files whose link may not open for everyone. Replace them with a link from Share → Copy link.
